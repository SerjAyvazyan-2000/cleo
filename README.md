# Клео — демо сайта салона красоты (Пермь)

Персональное демо на базе шаблона Mirelle для салона красоты «Клео», ул. Вильямса, 20/3. Сделка LID-36.

Сайт статический: `index.html` + `assets/` (css, js, images). Сборка не нужна.
Весь контент лежит в `assets/js/config.js`.

## Откуда данные
- Название, адрес, часы (ежедневно 9:00–21:00), WhatsApp, Telegram, ВК, рейтинг 5,0 / 406 оценок: карточка салона в 2ГИС
- Телефон +7 (342) 274-68-63: big-book-med.ru; +7 (919) 703-98-65: 2ГИС / WhatsApp
- Цены: вкладка «Цены» в 2ГИС (стрижки — описание карточки 2ГИС)

## Что скрыто до получения материалов
В `config.js` → `show` блоки выключены, их можно включить, когда придут материалы:
- `beforeAfter`: реальные парные фото «до/после» одной работы (окрашивание)
- `masters`: имена, фото и специализации мастеров (с согласия)
- `works`: фото работ салона
- `reviews`: отзывы с разрешением на публикацию
- `faq`: условия записи (предоплата, перенос, сертификаты)

Первый экран без фото: `hero.images` пустой. Добавьте 3 фото салона, и коллаж включится.

## Чего не хватает от салона
- Логотип и фирменные цвета (сейчас цвета шаблона)
- Фото интерьера и работ (в 2ГИС 366 фото, нужно согласие салона на использование)
- Парные фото окрашивания «до/после»
- Цены на маникюр, педикюр, окрашивание, наращивание и коррекцию бровей, наращивание ресниц
- Длительность услуг (для калькулятора времени)
- Ссылка на онлайн-запись (YClients/DIKIDI), если есть; сейчас запись идёт через WhatsApp
- Реквизиты для подвала
