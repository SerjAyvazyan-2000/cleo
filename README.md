# Клео — демо сайта салона красоты (Пермь)

Персональное демо на базе шаблона Mirelle для салона красоты «Клео», ул. Вильямса, 20/3. Сделка LID-36.

Сайт статический: `index.html` + `assets/` (css, js, images). Сборка не нужна.
Весь контент лежит в `assets/js/config.js`.

## Откуда данные
- **Прайс:** каталог услуг салона в 2ГИС (106 позиций, обновлён 11.09.2026). В демо 4 вкладки: волосы, ногти, брови и ресницы, лицо.
- **Фото:** галерея салона в 2ГИС, только фото, загруженные владельцем. Первый экран, прайс при наведении, портфолио, команда, «до/после».
- **Отзывы:** подтверждённые отзывы из 2ГИС, дословно, имя и инициал фамилии.
- **Контакты и рейтинг:** часы, WhatsApp, Telegram, ВК, рейтинг 5,0 / 406 оценок — 2ГИС. Городской телефон — big-book-med.ru.
- **Цвета:** золото с вывески «Клеопатра» и серо-бирюзовый из интерьера. Фирменного гайда нет.

## Согласовать с салоном перед публикацией
- Использование фото из галереи 2ГИС. Сейчас они подгружаются с сервера 2ГИС; после согласования их нужно скачать в `assets/images` и поменять ссылки в `PHOTO` в `config.js`.
- Фото сотрудников в блоке «Наша команда»: согласие каждого и подписи (имя, специализация).
- Фото «до/после» косметолога (лицо клиента): согласие клиента.
- Цитаты отзывов из 2ГИС.
- Актуальность цен (прайс в 2ГИС от 11.09.2026).

## Чего не хватает от салона
- Логотип в векторе и фирменные цвета
- Парные фото окрашивания «до/после» одной работы (сейчас «до/после» — уход за лицом)
- Длительность услуг (в калькуляторе пока только стоимость)
- Имена и специализации мастеров
- Ссылка на онлайн-запись (YClients/DIKIDI), если есть; сейчас запись через WhatsApp
- Реквизиты для подвала
